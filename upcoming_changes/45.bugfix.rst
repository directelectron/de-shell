An app that leaves torch out of its lock (``[tool.uv] exclude-dependencies = ["torch"]``) got no torch on its first run and lost the one it had on every upgrade; setup now keeps an installed torch (an ``--inexact`` sync) and installs one for the machine's GPU with ``--torch-backend=auto`` only when it is missing, does not load, or has no kernels for the GPU, and a failed install is reported in the setup overlay while the app still starts and the next launch retries.
